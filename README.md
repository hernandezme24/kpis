## 📝 Descripción

Sitio web estático diseñado para presentar de forma profesional e interactiva una diapositiva sobre **Indicadores de Gestión**. Incluye un visor de PDF embebido con un diseño moderno, responsive y visualmente atractivo.

El contenido abarca:

- Definición y características de los indicadores de gestión.
- Tipos de indicadores: eficiencia, eficacia, efectividad y productividad.
- Ejemplos prácticos y beneficios para la toma de decisiones.

## 👀 Vista previa

El sitio cuenta con:

- 🎨 **Diseño oscuro profesional** con paleta azul, dorado, verde lima y celeste.
- 🪟 **Visor PDF** con efecto glassmorphism y barra decorativa estilo sistema operativo.
- ✨ **Animaciones de entrada** suaves y progresivas.
- 📱 **Diseño responsive** adaptado a escritorio, tablet y móvil.
- 🔗 **Enlace de respaldo** para abrir el PDF en una pestaña nueva si el navegador no soporta la visualización embebida.

## 🚀 Cómo usar

### Opción 1: GitHub Pages (recomendado)

1. Sube todos los archivos a un repositorio de GitHub.
2. Ve a **Settings → Pages → Source** y selecciona la rama `main`.
3. Tu sitio estará disponible en:
   ```
   https://tu-usuario.github.io/nombre-del-repo/
   ```

### Opción 2: Abrir localmente

Simplemente abre el archivo `index.html` en cualquier navegador moderno.

## 🔄 Actualizar el PDF

Para reemplazar la presentación por una nueva versión:

1. Renombra tu nuevo archivo PDF a **`indicadores-gestion.pdf`**.
2. Reemplázalo en la carpeta `assets/`.
3. Haz commit y push.

> ⚠️ **Importante:** Usa siempre nombres de archivo **sin acentos, sin espacios y en minúsculas** para evitar errores de carga en servidores web.
